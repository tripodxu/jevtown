# 新精密仪器：前端现代化设计

日期：2026-10-28
状态：C 方向已确认，实施本轮；A/B 仅保留方向记录。

## 目标与边界

在不改 Worker、API、D1、共享引擎、检查/续跑/改版/对比/BYOK 等业务逻辑的前提下，将默认前端重构为「新精密仪器」：冷灰表面、电蓝信号色、锐利几何、清晰数据层级。首屏聚焦输入，复杂选项渐进披露；报告先给结论，再允许深入探索。

## C：本轮实施

### 视觉系统

- 默认主题为 `instrument`；夜巡、公报、经典继续可切换，主题持久化与 canvas 重绘不变。
- 使用现有语义令牌，统一冷灰底、白色工作面、电蓝主行动、细分隔线、小半径控件和克制阴影。
- 无框架、无图标库、无外部图片；图标使用内联 SVG。字体使用本地系统栈，避免字体下载与布局偏移。
- 统一排版、间距、控件高度、焦点态、触达目标和动效曲线。装饰只使用 CSS，动画仅操作 transform/opacity，并尊重 reduced-motion。

### 首屏与输入

- 宽屏使用「产品叙事 + 输入控制台」双栏，窄屏恢复单栏；主体最大宽度适当增加，正文行长仍受控。
- 首屏只突出类型、正文、样例与唯一主 CTA。定价、全城广播、受众选择放入原生 `<details>` 高级选项；保留所有原 DOM id、字段顺序语义和校验行为。
- 装饰人格网格只表达 100×100 的产品隐喻，不新增 canvas、scroll listener 或持续布局计算。

### 实时监控

- 先显示进度与核心 KPI，再突出逐格点亮的地图；曲线和调用流水作为次级分析区。
- 保留 `paintDelta` 增量绘制、`tally` 增量统计、150 行流水上限、图表悬停与屏幕阅读器里程碑播报。

### 报告与探索

- 顶部强化快报、关键数字和原文；目录保持锚点导航。
- 提供「速览 / 完整报告」展示切换：速览保留总览、传播、反应分布、地图、地形和人格声音；完整报告显示全部既有章节。切换只控制展示，不重新请求、不修改数据。
- 报告分组使用语义 section 与统一标题样式；对比、示例回放和深链保持原行为。

### 可访问性与响应式

- 保留跳转链接、可见焦点、表单标签、键盘地图、触摸点按、原生 dialog 和 live region 分层。
- 主控件触达目标至少 40px，移动端输入字号至少 16px；360/390/768px 不产生页面级横向滚动。
- 颜色不是唯一状态载体；四主题对比度继续由既有测试约束。

### 性能预算

- 不新增运行时依赖，不新增外部字体和图片请求。
- CSS/JS 只增加展示所需代码；报告示例继续 IntersectionObserver 懒渲染，canvas 继续增量绘制。
- 首屏动画不超过两处，避免 blur 大面积动画、视差和高频指针效果；CLS 目标 < 0.1。

### 验证

- `npm run lint`、`npm test` 全量通过。
- 浏览器检查首屏、高级选项、实时态、报告速览/完整、四主题、键盘、reduced-motion 与移动布局。
- 对比重构前后 DOM 契约、静态资源体积和截图；部署后通过 `https://jevtown.logicc.top` 验证首页、静态模块与 `/api/feed`。

## A/B：仅记录，暂不在本轮实现

### A：夜色观测台

深墨底、暖珊瑚信号色、非对称大标题，以夜间城市观测为核心隐喻。适合强化品牌记忆和实时地图氛围。本轮不改用该配色或布局。

### B：活人公报

米纸底、宋体标题、朱红印章与出版物式留白，强调中文内容的人文气质和长报告阅读。本轮不改用该字体与编辑式构图。
