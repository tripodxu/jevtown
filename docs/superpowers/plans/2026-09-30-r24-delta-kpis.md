# R24 · 前端轮：两版对比的数字对照——old → new 一眼读出差值方向

> 轮换位置：R23 创意 ⇒ **R24 前端** ⇒ R25 优化。preserve 纪律同前几轮。

## 缺口（代码级取证）

- `renderDelta` 给了"变好/变差人数 + 差分地图"，但**两版的头条数字没有并排**：
  到达/停下/乐见/反感，读者要在两份完整报告之间来回滚动做减法。
- 数据全在内存（`before.counters` / `after.counters`，对比区本就拉了第 1 版），零新增请求。

## 改动

1. `render.js` renderDelta：stats 行下加 `.delta-kpis` 四行对照——
   `到达 2,100 → 2,100（持平）` 形式；方向语义：乐见↑=好、停下↑=好、反感↑=坏、
   到达=中性（--ok/--bad/--muted 令牌着色差值）。
2. `styles.css`：`.delta-kpis`（两列网格：标签 + 等宽数字对 + 差值徽章）。
3. 顺带：对比区载入按钮旁的提示语与快报措辞对齐（不动结构）。
