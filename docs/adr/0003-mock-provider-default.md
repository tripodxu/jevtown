# ADR-0003 · mock 为默认通道

- 状态：已采纳
- 日期：2026-09-28
- 背景：真实 Jev 调用花钱（单波 600 人 ≈ $0.01–0.02）。开发、演示、测试、评审都需要
  零成本全流程可玩。
- 决策：`JEV_PROVIDER` 默认 `mock`。`shared/mock.js` 提供与真实 `ask` 同形状的假实现：
  按文本特征 + 人格属性算**确定性概率**。没有任何 key 时自动落 mock；填 key 即切真实。
- 理由：
  - 新用户/评审零门槛体验完整流程；
  - 测试全程 mock，不花钱也不需要 key（见 `docs/TESTING.md`）；
  - 确定性概率让演示结果可复现。
- 备选与否决理由：
  - 默认真实模型：首次体验即花钱，且需要引导配 key，门槛过高；
  - 录制成固定回放：覆盖不了"任意文本"的输入空间，mock 的启发式至少对任意输入有合理反应。
- 后果：**mock 数字不可用于成本/传播预估**——实测同一条帖子 mock 传遍全城 10,000 人，
  真实 Jev 第 2 波即停（见 `research/real-api-report.md`）。所有对外传播结论必须用真实
  通道复跑。
